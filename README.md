### Возможности

В этой реализации TaskManager можно зарегистрировать пользователя (ROLE будет USER). Регистрация с ролью ADMIN не предусмотрена (единственный админ добавлен в базу при ее создании username= test_1,  password = password123).

При входе пользователя в систему ему выдается токен, который используется для всех ручек UserController и TaskController.

Пользователям с ролью USER доступны все методы в UserController и все методы в TaskController, кроме метода удаления задачи. Удаление задачи доступно только роли ADMIN.

Цикл задач состоит из 3-х статусов: CREATED, IN_PROGRESS, DONE.

Задачу можно создать (status CREATED), при создании заполняется только description, исполнитель обязательно null.

Задачу можно изменить:
- Задачу можно взять в работу (status IN_PROGRESS), при этом обязательно указать исполнителя.
- Задачу можно завершить (status DONE), у завершенной задачи обязателен исполнитель. Завершить задачу можно только из статуса IN_PROGRESS.
- Можно вернуть задачу в созданные, при этом исполнитель выставляется null.
- Можно поменять исполнителя
- Можно поменять описание

Можно удалить задачу в любом статусе, доступно только роли Admin. При этом исполнитель выставляется в null.

Доступна фильтрация пользователей и задач.

Пользователи:
- Получить всех пользователей
- Получить пользователей у которых есть созданные задачи (где они авторы)
- Получить автора конкретной задачи
- Получить пользователей без созданных задач (нет авторства ни в одной из задач)
- Получить пользователей у которых есть назначенные задачи (где они исполнители)
- Получить исполнителя конкретной задачи
- Получить пользователей у которых нет назначенных задач (не являются исполнителем ни в одной из задач)
- Получить исполнителей задач, у которых задача находится в определенном статусе (в данной реализации либо в IN_PROGRESS либо в DONE)
- Найти пользователя по username

Задачи:
- Найти задачи конкретного автора
- Найти задачи конкретного исполнителя
- Найти задачи без исполнителя
- Найти задачи по статусу
- Найти задачи по дате создания
- Найти задачи по дате изменения
- Найти задачи по дате завершения
- Найти задачи по описанию

Метрики и логирование:
Логи пишутся в файл spring-boot-app.log. Доступны ручки актуатора health (всем), info и metrics авторизованным пользователям с ролью ADMIN. Есть две кастомные метрики: tasks.created и users.login.success
